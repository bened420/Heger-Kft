1. Fejlesztési terv: Mérföldkövek

A projekt fejlesztését szakaszokra bontjuk a hatékony munkavégzés érdekében. A cél egy modern és biztonságos banki szoftver létrehozása.

  • 1. Mérföldkő (3. hét): Weboldal létrehozása és verziókezelés
    Csapatnév és téma rögzítése, a projekt bemutató weboldalának elkészítése, valamint a Git alapú verziókövetés beüzemelése.

  • 2. Mérföldkő (6. hét): Tranzakciós és Számlakezelő Modul
    Bankszámlák közötti belföldi utalások logikája, számlatörténet generálása. Számlák egyenlegének biztonságos kezelése.

  • 3. Mérföldkő (9. hét): Pénzügyi és Valutaváltó Modul
    Deviza számlák kezelése, külső árfolyam API integrálása a valós idejű konverzióhoz. Hiteligénylési űrlapok.

  • 4. Mérföldkő (12. hét): Biztonsági és Riportolási Modul
    Tranzakciók naplózása, ügyintézői statisztikák. Hibakeresés és a rendszer összehangolásának befejezése.

2. Alkalmazott programozási nyelvek és IDE környezetek

Pénzügyi környezetben a stabilitás kritikus szempont, ezért az alábbiakat fogjuk használni:

  • Szerveroldal: Java Spring Boot vagy Node.js az adatkezeléshez.

  • Kliensoldal: React és Tailwind CSS a megfelelő felhasználói élmény elérése érdekében.

  • Adatbáziskezelő: PostgreSQL a tranzakciós adatok biztonságos tárolására.

  • Fejlesztői szoftverek: IntelliJ IDEA, VS Code, WebStorm.

3. Választott technológiák és megoldások

A biztonságos bankolás miatt szigorú elveket követünk a fejlesztés során:

  • Forráskód kezelés: Git repozitórium használata a közös munkához.

  • Fejlesztési elvek: Kanban és Scrum.

  • Biztonság: Bcrypt alapú jelszótitkosítás és JWT tokenes authentikáció.

  • Hálózati kommunikáció: REST API végpontok kialakítása a szerver és a kliens közt.

5. A szoftver tesztelésének szabályai

Egy banki programnál elengedhetetlen a megfelelő ellenőrzés. Részleges, de alapos tesztelést tervezünk:

  • Kódszintű tesztek: A pénzmozgást kezelő logikák automatizált vizsgálata.

  • Biztonsági átvizsgálás: A hitelesítési folyamatok és a sérülékenységek ellenőrzése.

  • Integrációs ellenőrzés: Az adatbázis kapcsolatok és külső rendszerek tesztelése.
