Projektben használt szakmai és idegen fogalmak:

  • 2FA (Two-Factor Authentication / Kétlépcsős azonosítás): Olyan biztonsági eljárás, ahol a felhasználónak a jelszava mellett egy második, független hitelesítő elemet (pl. SMS-ben vagy hitelesítő alkalmazásban kapott 6 számjegyű kódot) is meg kell adnia.
  • ACID: Az adatbázis-tranzakciók megbízhatóságát garantáló négy alapelv: atomiság (minden művelet lefut vagy semmi), konzisztencia (mindig érvényes állapot), izoláció (a párhuzamos műveletek függetlensége) és tartósság (a mentett adatok megmaradnak).
  • AFR (Azonnali Fizetési Rendszer): A Magyar Nemzeti Bank által előírt hazai bankközi elszámolási rendszer, amely az 50 millió forint alatti eseti forint átutalásokat az év minden napján 24 órában, legfeljebb 5 másodperc alatt jóváírja a fogadó fél számláján.
  • Aktor (Actor): Az UML modellezésben a rendszert kívülről használó emberi felhasználó vagy külső gépi komponens (pl. külső árfolyam-szolgáltató), amely közvetlen kapcsolatba lép a rendszer funkcióival.
  • API (Application Programming Interface): Alkalmazásprogramozási felület, amely előre definiált szabályok szerint lehetővé teszi a különböző szoftverek közötti adatcserét és kommunikációt.
  • Audit Log (Audit napló): Időbélyeggel ellátott biztonsági eseménynapló, amely rögzíti a rendszerben lezajló felhasználói, pénzügyi és adminisztrátori műveleteket felelősségvizsgálat céljából.
  • Bcrypt: Erős, egyirányú kriptográfiai hash algoritmus, amely automatikus sózással (salt) és lassítással védi a jelszavakat az illetéktelen visszafejtés ellen.
  • CDV kód (Cégjegyzék- és számlaellenőrző algoritmus): A magyar bankszámlaszámok utolsó számjegyét meghatározó matematikai algoritmus, amellyel a rendszer azonnal felismeri az elgépelt vagy érvénytelen számlaszámokat.
  • CI/CD (Continuous Integration / Continuous Deployment): Folyamatos integráció és folyamatos telepítés: olyan automatizált eljárás, amelynél a forráskód tesztelése és szerverre juttatása automatikusan történik.
  • Deviza: Nemzetközi fizetési forgalomban használt, külföldi pénznemre szóló bankszámlakövetelés vagy utalás, amely nem kézzelfogható készpénz (ez utóbbi a valuta).
  • Eclipse: Széles körben elterjedt fejlesztői környezet, amelyet főként Java és vállalati háttéralkalmazások fejlesztésére használnak.
  • ER diagram (Entity-Relationship Diagram): Egyed-kapcsolat diagram: vizuális adatbázis-tervező eszköz, amely az egyedeket (táblákat), azok tulajdonságait és a köztük lévő kulcskapcsolatokat ábrázolja.
  • FK (Foreign Key / Idegen kulcs): Egy relációs adatbázistábla mezője, amely egy másik tábla elsődleges kulcsára mutat, ezzel biztosítva a táblák közti kapcsolatot és hivatkozási épséget.
  • GDPR (General Data Protection Regulation): Az Európai Unió általános adatvédelmi rendelete, amely a magánszemélyek személyes adatainak védelmét és jogszerű kezelését írja elő.
  • Git: Elosztott verziókezelő szoftver, amely rögzíti a fájlok változásait, és támogatja a több fős csapat párhuzamos munkáját.
  • HTTPS (HyperText Transfer Protocol Secure): A webes kommunikáció titkosított változata, amely TLS kapcsolaton keresztül védi az adatforgalmat a lehallgatás ellen.
  • IDE (Integrated Development Environment): Integrált fejlesztői környezet, olyan összetett program (például VS Code, IntelliJ), amely kódszerkesztőt, fordítót és hibakeresőt biztosít.
  • IntelliJ IDEA: A JetBrains által készített intelligens fejlesztőkörnyezet, amely kiemelkedő támogatást ad Java és Spring Boot projektekhez.
  • JTM (Jövedelemarányos Törlesztési Mutató): A Magyar Nemzeti Bank adósságfék-szabálya, amely meghatározza, hogy az ügyfél igazolt nettó jövedelmének mekkora hányada fordítható legfeljebb hiteltörlesztésre.
  • JWT (JSON Web Token): Nyílt szabványon alapuló, digitálisan aláírt azonosító token, amellyel állapotmentes (stateless) módon igazolható a felhasználó bejelentkezése a szerver felé.
  • Kanban: Vizuális agilis folyamatmenedzsment módszer, amely táblák és kártyák segítségével követi nyomon a feladatok haladását.
  • MTBF (Mean Time Between Failures): Hibák közötti átlagos működési idő: a rendszer megbízhatóságát mérő mutató, amely megadja, hogy átlagosan hány üzemóra telik el két váratlan leállás között.
  • MTTR (Mean Time To Repair): Hiba utáni helyreállítási átlagos idő: azt méri, hogy mennyi idő szükséges a rendszer normál működésének visszaállításához egy meghibásodás után.
  • Node.js: JavaScript futtatókörnyezet, amely a böngészőn kívül teszi lehetővé eseményvezérelt, nagy teljesítményű szerveroldali alkalmazások futtatását.
  • OWASP (Open Web Application Security Project): Nemzetközi szervezet és közösség, amely a szoftverbiztonság javítására összpontosít, és rendszeresen közzéteszi a leggyakoribb webes sebezhetőségek (OWASP Top 10) jegyzékét.
  • PK (Primary Key / Elsődleges kulcs): Egy adatbázistábla rekordjait egyedien és megismételhetetlenül azonosító kulcsmező.
  • PostgreSQL: Nyílt forráskódú, robusztus relációs adatbázis-kezelő rendszer, amely kiválóan támogatja a komplex lekérdezéseket és az ACID tranzakciókat.
  • Postkondíció (Postcondition / Utófeltétel): Az a garantált rendszerállapot és adatváltozás, amely egy Use Case (használati eset) sikeres lefutása után érvénybe lép.
  • Prekondíció (Precondition / Előfeltétel): Azon követelmények és feltételek összessége, amelyeknek maradéktalanul teljesülniük kell ahhoz, hogy a Use Case (használati eset) egyáltalán elindítható legyen.
  • PSD2 (Revised Payment Services Directive): Az Európai Unió pénzforgalmi irányelve, amely kötelezővé teszi az erős ügyfélhitelesítést és támogatja a nyílt bankolási (Open Banking) felületeket.
  • React: Komponensekre épülő JavaScript könyvtár reszponzív és gyors felhasználói felületek készítéséhez.
  • REST API (Representational State Transfer): Szabványos HTTP műveleteket (GET, POST, PUT, DELETE) használó hálózati végpontrendszer, amelyen keresztül a böngésző és a szerver JSON formátumban kommunikál.
  • Scrum: Agilis fejlesztési keretrendszer, amely rövid ciklusokban (sprintekben) szervezi a csapat munkáját és a szoftver fokozatos átadását.
  • Spring Boot: Java nyelvre épülő vállalati keretrendszer, amely gyors és megbízható alapot nyújt mikroarchitektúrás backendekhez és REST szolgáltatásokhoz.
  • SRS (Software Requirements Specification): Szoftverkövetelmény-specifikáció: a rendszer funkcionális elvárásait és működési korlátait részletező hivatalos tervdokumentáció.
  • Tailwind CSS: Segédosztályokra épülő CSS keretrendszer, amely közvetlenül a HTML kódban teszi lehetővé a modern felületek gyors megformázását.
  • TLS (Transport Layer Security): Kriptográfiai biztonsági protokoll, amely a kliens és a szerver közötti hálózati adatfolyam titkosítását és sértetlenségét garantálja.
  • Tranzakció: Egy logikai egységként kezelt műveletsor az adatbázisban, amely vagy teljesen végbemegy, vagy hiba esetén minden változtatás visszavonásra kerül.
  • Use Case (Használati eset): Az UML modellezésben egy aktor és a rendszer közötti célorientált interakciósorozat leírása, amely az érintett szereplő számára értékes üzleti eredményt szolgáltat.
  • VS Code: Népszerű, pehelysúlyú és bővíthető kódszerkesztő a mindennapi webfejlesztési munkákhoz.
  • WebStorm: Kifejezetten JavaScript és webes technológiákhoz tervezett prémium fejlesztői környezet.
